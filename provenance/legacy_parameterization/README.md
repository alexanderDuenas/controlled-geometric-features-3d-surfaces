
# Legacy parameterization provenance

The files in this directory are retained only to document historical
parameterization stages that preceded the final public 40-feature design.

They are **not** operational inputs to `run_all.py`, and values appearing here
must not be interpreted as the prescribed-width population of the final
MethodsX validation.

The authoritative public design catalog is:

```text
data/parameterization/feature_design_40.csv
```

which contains the final 40 controlled geometric features, using prescribed
widths of 2, 5, 10, 20 and 50 mm across the four feature families and two
parameterization levels.
