# Terminology

The manuscript terminology is authoritative.

| Manuscript term | Legacy/internal identifier that may remain in the neutral implementation |
|---|---|
| feature ID | `probe_id` |
| controlled geometric feature | `probe` |
| prescribed width | `nominal_width_mm` |
| parameterization level | `replicate` |
| observable / not observable | legacy visibility labels where applicable |
| identity-view binding | legacy pair/source-target terminology where applicable |

Legacy names are retained only where renaming would add implementation churn
without changing the neutral-example scientific result.

They must not be interpreted as alternative manuscript terminology.

The public UAV validation files use the manuscript terminology.
